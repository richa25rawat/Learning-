# Guide Template: Installing Python & Setting Up Your System

Here is the step-by-step instructions to install Python IN WINDOWS, configure an Integrated Development Environment (IDE), and verify the installation.

**⬇️Step 1: Download & Install Python**
--> Visit the official download page: [python.org/downloads](https://www.python.org/downloads/).
--> Click the *"Download Python 3.x.x"* button. (Click on the latest version shown.)
--> Open the downloaded *.exe* installer file.
  **🚨CRITICAL STEP:** Check the box at the bottom that says **"Add python.exe to PATH"**. If you skip this, the terminal will not recognize Python commands.--
-->Click **"Install Now"**.
 >>Once installation complete, click **"Disable path length limit"** if the option appears.

**💻Step 2: Verify the Installation**
-->Open either Command Prompt or PowerShell, type the following command,

## ⚙️Check the Python Version 
--> *python --version, then press Enter* or *python -V , then press Enter*

**📄Step 3: Choose Your Code Editor...**
--> To write and run your scripts, install a text editor or Integrated Development Environment (IDE).
--> Here we will use Visual Studio Code:
       ✅*Visual Studio Code (VS Code)](https://code.visualstudio.com/)*
       ✅Once installed --> open VS Code, go to the *Extensions tab* search for *"Python"* (by Microsoft), and click *Install*.
 **⚡ Step 4: Create and Run Your First Script**     
▶️ Let's create your first program with a Hello GitHub.
    1️⃣ Open your code editor i.e. VS Code.
    2️⃣ Create a new file and save it exactly as `Practice.py`. (*File name should have extension .py*)
    3️⃣ Type your code --> print("Hello GitHub").
    4️⃣ Save the file on your desired location.
    5️⃣Click on the Play button ▶️ in the top-right corner of VS Code or alternatively use shortcut **Ctrl + F5** to run program without debugging.
    If you see the message printed in your console, your system  is ready for coding!
